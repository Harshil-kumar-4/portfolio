System Architecture

Autonomous Multi-Cloud FinOps Engine

LangGraph + Python — a state-machine agent that automates rightsizing analysis while encoding the production-safety judgment a human SRE applies instinctively. A few implementation details below are intentionally kept high-level — ask me about the internals.

SRE Crash-Detection Guardrail

Before recommending a downsize, the agent checks whether the service is already failing — a deliberate safeguard against false-positive resizing on anything actively crashing. How it makes that call is one of the more interesting design decisions in the system.

Multi-Cloud Abstraction

A ProviderRegistry architecture that supports Azure, Databricks, and Snowflake behind one consistent interface.

Deterministic Execution

All monetary arithmetic and rate lookups are offloaded directly to Python — eliminating LLM hallucination risk from financial decisions.

Token Efficiency Pipeline

A deliberate data-shaping strategy cuts token usage 75–85% with zero drop in decision quality — the specific technique is part of the system's design, and one I'm happy to walk through in a conversation.
